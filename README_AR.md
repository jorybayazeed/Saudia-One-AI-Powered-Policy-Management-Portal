# Saudia One — IT OPM Enterprise v1.8

إصدار ثنائي اللغة يعمل محليًا ويستخدم حزمة **IT_OPM_RAG_Enterprise v3.0** للإجابة المقيدة بدليل تقنية المعلومات.

## ثبات الواجهة

تم بناء v1.8 فوق واجهة v1.7 نفسها. لم يتغير ملف CSS المبني، ولم يتغير `dist/index.html`، ولم يتغير ترتيب الصفحات أو القوائم أو الأزرار. التعديلات داخل محرك الفهم والاسترجاع والسياق فقط، مع تصحيح اتجاه نص كل رسالة حسب لغتها.

## تحسينات محرك الإجابة

- تثبيت الكيان المذكور قبل البحث: `EDRAK` و`TMS` و`LMS` و`Freshdesk` والنسخ الاحتياطي.
- تحديد نوع السؤال قبل اختيار السجل: رابط، بريد، مسؤول، توقيت، خطوات، عطل، متابعة أو إغلاق.
- منع إرجاع سجل من نظام مختلف حتى لو تشابهت كلمات عامة مثل «المسؤول» أو «المتابعة».
- استخدام سياق المحادثة للأسئلة القصيرة مثل: `وش الرابط؟`، `عطيني الإيميل`، `مين المسؤول؟` و`متى؟`.
- تحسين فهم العربية الفصحى واللهجة السعودية والجداوية والإنجليزية والأسئلة المختلطة.
- إجابات مباشرة مختصرة للحالات الشائعة مع بقاء السجلات والمصدر والصفحة والروابط المعتمدة.
- استمرار قاعدة الامتناع: لا توجد إجابة من خارج سجلات IT OPM المعتمدة، ولا توجد خطوات إصلاح مخترعة.

## أمثلة تم إصلاحها

- `When should the backup EDRAK server be used?` يرجع إجراء EDRAK الصحيح، لا سجل مراوح الخادم.
- `How do I create a new learning path in TMS?` يرجع إجراء إنشاء المسار، لا نظام Freshdesk.
- `من المسؤول عن متابعة النسخ الاحتياطية؟` يرجع مسؤول النسخ، لا إجراء TMS.
- `ما البريد الإلكتروني المعتمد لقسم تقنية المعلومات؟` يرجع بريد الدعم، لا رقم نشر الوثيقة.
- `وش الرابط؟` بعد سؤال Freshdesk يعرض رابط Freshdesk من سياق المحادثة.

## المزايا المحفوظة

- الشات النصي والصوتي بالعربية والإنجليزية.
- روابط Freshdesk وبريد دعم تقنية المعلومات عند ارتباطها بالسجل.
- حفظ المحادثات محليًا لكل حساب واستعادة آخر جلسة.
- مولّد السياسات الثنائي اللغة ومكتبة السياسات ومسار المراجعة.
- 173 سجلًا ذريًا، و29 إجراءً، و29 ملخصًا.
- إظهار `Record ID` والقسم والصفحة لكل نتيجة معتمدة.

## التشغيل السريع على macOS

```bash
chmod +x تشغيل_البرنامج_على_ماك.command
./تشغيل_البرنامج_على_ماك.command
```

ثم افتح `http://127.0.0.1:4173`.
