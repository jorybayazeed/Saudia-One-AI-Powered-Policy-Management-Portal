# قاعدة معرفة IT OPM Enterprise

تم استبدال قاعدة المعرفة السابقة بحزمة `IT_OPM_RAG_Enterprise` الإصدار `3.0-enterprise`.

## الحقول المستخدمة

- الاسترجاع الدلالي المحلي: `dense_text`.
- الاسترجاع بالكلمات وBM25: `sparse_text`.
- صياغة الإجابة: `answer_text` و`answer_fields` و`structured_steps` فقط.
- الاستشهاد الإلزامي: `Record_ID` و`Section` و`Source_Page`.

## سلوك الاسترجاع

- أسئلة من/متى/وين/كم: طبقة `atomic`.
- أسئلة كيف/الخطوات/الإجراء/التعطل: طبقة `procedure` كاملة.
- الأسئلة العامة: طبقة `summary` مع سجلاتها الذرية.
- الأسئلة الغامضة: طلب توضيح.
- الأسئلة خارج نطاق IT OPM: امتناع عن الإجابة.

يعمل الإصدار المحلي دون إرسال البيانات إلى خدمة خارجية. الاسترجاع الهجين يتم داخل المتصفح، لذلك يستخدم تشابهًا دلاليًا محليًا على `dense_text` مع BM25 على `sparse_text`، وليس نموذج Embeddings سحابيًا.
