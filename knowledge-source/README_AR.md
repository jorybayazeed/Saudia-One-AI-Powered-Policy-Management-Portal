# حزمة IT OPM الجاهزة لتطبيق RAG

## الملفات

- `markdown/`: ملف Markdown لكل مجموعة استرجاع. استخدم هذه الملفات لاسترجاع الإجراء أو القسم كاملًا.
- `grouped_chunks.jsonl`: نفس المجموعات بصيغة JSONL مع Metadata.
- `records.jsonl`: عدد 173 سجلًا منفصلًا للاسترجاع الدقيق.
- `enriched_records.csv`: نسخة السجلات مع حقول الربط والسياق والكلمات العربية.
- `manifest.json`: ملخص المجموعات وعدد السجلات.
- `chatbot_system_prompt_ar.txt`: تعليمات مقترحة للمساعد.
- `build_it_opm_kb.py`: سكربت إعادة توليد الحزمة من ملف Excel الأصلي، ولا يحتاج مكتبات خارجية.

## تشغيل السكربت

```bash
python build_it_opm_kb.py "IT_OPM_Reviewed_RAG_Ready_Dataset(1).xlsx" output_kb
```

اسم الورقة الافتراضي هو `Reviewed Dataset`. لتحديد اسم آخر:

```bash
python build_it_opm_kb.py input.xlsx output_kb --sheet "Reviewed Dataset"
```

## استراتيجية الاسترجاع الموصى بها

1. ابحث أولًا في `grouped_chunks.jsonl` أو ملفات `markdown/`.
2. للأسئلة الإجرائية، أعد المجموعة كاملة ولا تكتفِ بسجل Step واحد.
3. للأسئلة الدقيقة، ابحث أيضًا في `records.jsonl`.
4. إذا ظهر سجل منفصل، استخدم `retrieval_group_id` لجلب المجموعة الكاملة المرتبطة به.
5. استخدم `parent_record_id` لفهم الخطوات الفرعية والفروع.
6. رتّب الخطوات باستخدام `sequence_path` مع الحفاظ على القيم مثل `2A` و`9.1`.
7. صفِّ النتائج على `status = Active` والإصدار الفعّال.
8. اذكر في الإجابة `Record_ID` والقسم والصفحة.

## مثال

السؤال:

> ماذا أفعل إذا تعطل نظام إدراك؟

المجموعة المتوقعة:

- `PROC-2.8`
- السجلات `REC-105` إلى `REC-110`

يجب أن تعرض الإجابة الخطوات الخمس بالترتيب، لا أن تعرض خطوة منفصلة فقط.
